# Лида Мастерица

Одностраничный сайт-визитка музыкальной мастерской: ноты, нотный стан,
мини-плеер с синтезируемой мелодией и играемая клавиатура на Web Audio API.

Открыть локально:

```bash
python serve.py 8123
```

Затем <http://127.0.0.1:8123/>. Порт можно изменить любым свободным.

Подробности — в [WIKI.md](WIKI.md).

Демо-контакты в проекте вымышлены и приведены для примера.
