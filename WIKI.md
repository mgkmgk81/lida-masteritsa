# Лида Мастерица — wiki проекта

## Обзор

**Лида Мастерица** — одностраничный сайт-визитка музыкальной мастерской.
После обновления проект переведён в **музыкальный стиль**: добавлены декоративные
ноты, нотный стан, анимированный эквалайзер и интерактивная клавиатура,
на которой можно сыграть ноты прямо в браузере. Контакты и биография
в демонстрационной версии вымышлены и приведены для примера.

| Параметр | Значение |
| --- | --- |
| Тип | Статический сайт-визитка (landing page) |
| Тема | Музыкальная мастерская: вокал, фортепиано, аранжировки |
| Язык интерфейса | Русский |
| Верстка | Адаптивная, от 320 px |
| Технологии | HTML5, CSS3, ванильный JavaScript, Web Audio API |
| Сборка | Не требуется |
| Внешние аудиофайлы | Не используются — звук генерируется в браузере |
| GitHub Pages | <https://mgkmgk81.github.io/lida-masteritsa/> (ветка `main`, корень `/`) |

## Структура страницы

1. **Шапка** — логотип с нотой, навигация, кнопка «Записаться».
2. **Герой-блок** — имя, описание, кнопки-действия, цифры и декоративный нотный стан.
3. **«Обо мне»** — история мастерской и направления работы.
4. **«Что я делаю»** — три карточки услуг с стартовыми ценами.
5. **«Ноты и звук»** — музыкальный плеер с мелодией и играемой клавиатурой.
6. **«Контакты»** — каналы связи и мастерская.
7. **Подвал** — копирайт с автообновляемым годом и ссылка наверх.

## Музыкальный раздел

Добавленный блок `#music` содержит:

- **Кнопку воспроизведения** — запускает и останавливает короткую мелодию
  приветствия (11 нот, темп ~0,34 с на долю).
- **Эквалайзер** — 16 полос, высота которых берётся из `AnalyserNode`
  в реальном времени. При нажатии на клавиши полосы кратко «пульсируют».
- **Клавиатуру** — 8 кнопок нот октавы (до–си и верхняя до). Каждая кнопка
  воспроизводит свой тон и подсвечивается при игре мелодии.
- **Анимацию нот** —/decorative символы ♪ ♫ ♩ ♬ 𝄞 плавают на фоне страницы
  и «прыгают» на нотном стане в первом экране.

Звук создаётся через `AudioContext`: осциллятор типа `triangle` + огибающая
громкости через `GainNode`. Никаких mp3/wav-файлов и внешних библиотек нет.
Браузер разрешает запуск звука только после действия пользователя, поэтому
звук включается по клику по кнопке или клавише.

## Файлы проекта

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка, контент, ноты и разметка плеера |
| `styles.css` | Дизайн-система, нотный стан, анимации, адаптивность |
| `script.js` | Год, появление блоков, генерация звука и эквалайзер |
| `serve.py` | Локальный сервер на `127.0.0.1` с отключённым кэшированием |

## Дизайн

- **Палитра:** тёплый бежевый фон (`#f6f1e7`), фиолетовый акцент (`#5b4b8a`),
  золотой (`#a97928`), тёмно-фиолетовый текст (`#241f31`).
- **Типографика:** заголовки — `Cormorant Garamond`, текст — `Manrope`.
  Ноты используют системный символьный шрифт `Segoe UI Symbol`.
- **Анимации:** плавная прокрутка, появление блоков, «дрейф» нот на фоне,
  покачивание нот на стане, реакция клавиш и эквалайзера на звук.
- **Доступность:** декоративные ноты скрыты от скринридеров через `aria-hidden`,
  учитывается системная настройка `prefers-reduced-motion`.

## Как запустить

Способ 1 — открыть `index.html` двойным щелчком в браузере.

Способ 2 — локальный сервер без кэширования (рекомендуется):

```bash
python serve.py 8123
```

Затем открыть <http://127.0.0.1:8123/>. Порт можно заменить любым свободным,
например `python serve.py 3000`. Сервер слушает только `127.0.0.1`, а заголовки
`Cache-Control: no-store` гарантируют, что браузер не покажет старую версию
страницы из кэша.

Универсальный вариант без дополнительного файла:

```bash
python -m http.server 8000
```

Затем открыть <http://localhost:8000>.

## Как редактировать

- Тексты, цены и контакты — в `index.html`.
- Мелодию можно изменить в массиве `melody` в `script.js`: каждый элемент
  — это `[частота_в_Гц, длительность_в_долях]`.
- Темп задаётся переменной `beat` в `script.js`.
- Цвета и шрифты — переменные в блоке `:root` в начале `styles.css`.
- Символы нот в декоре меняются в `.floating-notes` и внутри `.staff`.
